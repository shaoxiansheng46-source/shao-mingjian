# 用户操作手册

## 真实单候选计算

1. 打开“真实物理计算”。
2. 确认真实磁芯、3C95 材料、骨架和利兹线名称。
3. 选择 PS 或 PSP，填写 Np、Ns、P1/P2、气隙和间距。
4. 填写 Primary/Secondary 端电压、电流采样及时间序列。
5. 点击“运行真实物理计算”。
6. 查看结构 SVG、电磁/绕组损耗、漏感、来源和限制。
7. 修改输入后旧结果会标记失效，重新计算后才显示新结果。

## 真实结构优化

1. 进入“真实结构优化”。
2. 设置固定真实数据和显式波形。
3. 设置匝数、PS/PSP、P1、间距和磁芯余量范围。
4. 设置严格匝比、磁密和励磁电感约束。
5. 用小种群/代数先运行，观察进度和计算计数。
6. 在“全部候选”“研究性可行”“Pareto”间切换。
7. 点击候选查看实际结构；使用方案比较选择两个候选。
8. 导出 JSON 保存完整快照，CSV 用于表格分析。

## 状态含义

- 研究性可行：当前几何和研究约束通过，不代表工程 PASS。
- 几何淘汰：窗口、绝缘或制造排布失败。
- 物理失败：真实计算缺少有效指标或 Provider 失败。
- UNKNOWN：尚未有热、COMSOL 或样机工程验证。
