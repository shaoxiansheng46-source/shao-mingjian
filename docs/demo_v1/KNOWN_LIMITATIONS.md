# 已知限制

1. 漏感与邻近损耗尚未通过 COMSOL 或样机全面校核，绝对值只能作为研究性指标。
2. 热阻网络、温升和热点模型未实现，相关结果为 null/not_implemented。
3. 不从直流母线电压自动构造绕组端波形，真实损耗需要用户提供一致的电压/电流时序。
4. 首版网页优化固定真实磁芯、骨架和一条已加载真实导线；多数据库记录类别优化尚未开放。
5. 组合磁芯高保真计算、三维端部漏磁、COMSOL 自动化和工程认证报告未实现。
6. 研究性可行不是工程 PASS；所有当前真实候选 `engineering_status=UNKNOWN`。
7. 大规模真实优化需要独立任务队列、资源限额和持久化数据库；Demo 预算上限为种群 32、代数 20、评估 256。
