# SST Demo 模型说明

本 Demo 使用随附 `SST_V1_4_Demo_Data` 的原始 JSON 作为唯一演示数据库。计算核心位于 `backend/app/core/engine.py`，参考枚举和 NSGA-II 都调用 `evaluate_candidate`。

已实现：

- `DAB_SPS`、50% 对称双极性方波、system_sps 闭环；
- 整数 `Np/Ns` 候选生成，动态电压比不再固定 `Ns=Np/2`；
- 同心 P-S、零气隙、集成漏感、一维合成漏感模型；
- 实际线材外径排布、层数、并联根数、平均匝长、Rdc；
- SPS 分段线性电流、确定性谐波损耗、iGSE 三角磁通磁芯损耗；
- 双节点合成热网络，热点值固定为 `null`；
- 参考完整枚举与 pymoo NSGA-II，固定种子、输入快照、数据哈希、模型版本和运行结果持久化。

明确未实现/保持阻断：

- 工程模式、非零气隙量化、外置电感、给定电流模式、P-S-P/分段模板；
- FEM/CFD、瞬态热、真实热点、外部验证、系统效率与 ZVS；
- 真实厂家/实测数据的工程资格声明。

这些边界会在输入校验、结果等级和报告中保留，不会用默认值冒充工程模型。
