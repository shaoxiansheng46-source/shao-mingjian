# 范围、限制与下一步

## 已实现

- 一个候选结构和一个工作点快照的统一编排；
- 复用 Phase 3、4A、4B 的实际计算服务；
- PS/PSP 物理分段与电气绕组聚合保持一致；
- 数据、模型、候选和激励哈希追溯；
- OpenMagnetics 可选调用及不可用/输入不足的明确诊断；
- 研究性结果等级和热点 `null` 语义。

## 未实现

- 热阻网络、温升、热点和外置电感热模型；
- 磁芯损耗的本地统一服务；
- 统一层接入现有 API、前端、枚举或 NSGA-II；
- COMSOL/FEM 或样机校准；
- 组合磁芯高保真联合几何。

因此 Phase 5A 的统一结果可用于研发对照和候选检查，不能作为工程认证结论。
后续若进入优化器，应先把约束残差、预算、失败原因和多工况快照纳入独立的
`OptimizationService`，并保持旧 Demo 回归路径不变。
