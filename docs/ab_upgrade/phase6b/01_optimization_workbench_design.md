# Phase 6B 真实结构优化工作台设计

## 范围

Phase 6B 在 Phase 5D 的真实单候选页面旁增加“真实结构优化”视图。它只编排 Phase 6A 的混合变量 NSGA-II 和 Phase 5A 统一评估服务，不复制磁芯损耗、绕组损耗、漏感或几何公式。

现有 synthetic Demo、旧版 `/api/v1.4` 任务链和 Phase 5D `/api/v1.5` 物理单候选链保持原路径。Phase 6B 的接口前缀为 `/api/v1.6`，请求必须声明 `data_source=external_database`，不会静默回退 synthetic。

## 页面信息架构

- Provider 与真实数据状态：版本、可用性、禁止 synthetic 回退提示。
- 工况输入：绕组端电压、电流/电压采样序列、频率、功率和环境温度。
- 固定数据：OpenMagnetics 磁芯、材料、骨架和导线。
- 搜索变量：整数匝数、PS/PSP、PSP P1 分段、气隙与磁芯间隙。
- 任务状态：进度、代数、评估数、唯一候选、缓存命中、几何淘汰、研究性可行数和 Pareto 数。
- 结果：全部/研究性可行/Pareto 标签页、实际目标散点、结构 SVG、方案详情、两方案比较和 JSON/CSV 导出。

参数改变后会清除旧结果并显示“结果已失效”；新任务完成前不展示旧方案作为当前方案。

## 设计边界

本阶段不引入热网络、COMSOL、三维 CAD、DAB 波形求解器或混合变量优化前端之外的新物理模型。没有波形时真实任务会失败并给出缺失字段诊断；页面不把旧 synthetic 温升显示为真实温升。
