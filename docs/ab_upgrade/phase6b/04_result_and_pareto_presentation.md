# 结果、Pareto 和结构展示

## 进度

页面显示任务状态、当前代数、已评估数量、唯一候选数、物理成功数、缓存命中、几何淘汰、研究性可行数和 Pareto 数。进度来自 Phase 6B manager 读取 Phase 6A evaluator 汇总，不根据时间猜测。

## 候选表

- “全部”展示所有实际评估过的唯一候选，包括几何淘汰和物理失败。
- “研究性可行”只展示 `research_feasible=true`。
- “Pareto”只展示真实非支配前沿。
- 单击候选可查看变量、目标、Bmax、Lm、Pcore、完整绕组损耗、漏感和状态。

当前页面的目标散点使用实际任务返回的目标数组；没有可行候选时显示诊断文本而不绘制固定点。点击点或表格行会联动结构详情。

## 可信度显示

漏感仍是研究性 native/OpenMagnetics 对照模型，未经过 COMSOL 或样机校核；热模型未接入，因此温升显示为“未计算（热模型尚未接入）”。页面以 `UNKNOWN` 显示工程状态，不输出工程认证结论。

## 导出

JSON 直接导出完整输入、变量空间、case 快照、所有评估尝试、唯一候选、Pareto、进度和复现信息。CSV 输出所有唯一候选的核心变量、目标、关键性能和工程状态。
