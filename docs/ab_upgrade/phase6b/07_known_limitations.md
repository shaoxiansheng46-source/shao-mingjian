# 已知限制

1. 这是研发型工作台，不能替代 COMSOL、样机或绝缘/热设计认证。
2. 首版固定真实磁芯、材料、骨架和同一条导线；尚未把多个真实数据库记录作为可优化类别变量加载。
3. Phase 6A 的气隙变量目前作用于候选结构/快照边界；磁芯选择在本阶段固定，复杂组合磁芯没有加入高保真优化。
4. 必须由用户提供完整、同长度、周期一致的原副边电流和电压采样；本阶段不根据直流母线电压自动生成波形。
5. 热网络、热点和温升未接入，页面不得显示旧 synthetic 温升。
6. 漏感和邻近损耗的工程精度仍未用 COMSOL/实物验证；结果保留模型状态和限制说明。
7. 本阶段使用小预算上限（种群 32、代数 20、评估 256）保护网页任务；生产规模运行需要单独的任务队列、资源限额和持久化存储。
8. 当前工作环境未完成 Playwright 自动点击验证，已完成真实 HTTP/API 小预算联调。
