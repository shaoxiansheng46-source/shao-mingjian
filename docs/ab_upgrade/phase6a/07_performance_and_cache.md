# 性能、预算与缓存

台账缓存键包含候选结构哈希、激励快照哈希、Phase 6A 模型版本和完整配置。候选、工作点或模型版本变化都会失效；缓存命中只复制已有结果并标记 `cache_hit=true`，不改变数值。

每次运行保存：

- 所有评估尝试（含缓存命中）；
- 所有唯一候选；
- 几何淘汰、Provider 不可用、物理失败和研究性可行候选；
- `candidate_hash`、`excitation_hash`、`evaluation_key`、耗时、诊断和完整 Phase 5A 结果；
- Pareto rank 和重现信息。

真实调用耗时取决于 OpenMagnetics 数据库和候选几何。小规模基准的 8 次评估约 5.8 秒（Windows 当前环境，含 Provider 初始化），适合先用 4×2 的小任务检查，再增加预算。暂未做并行物理计算，避免数据库初始化和结果追溯被并发污染。
