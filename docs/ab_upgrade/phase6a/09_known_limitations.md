# 已知限制

- 这是研究型优化，所有候选的 `engineering_status` 为 `UNKNOWN`，没有热网络、热点温升或工程 PASS。
- 漏感仍是 Phase 4A 研究模型，尚未通过 COMSOL 或样机标定；可用于研究性指标，不能作为认证值。
- 完整绕组损耗依赖 OpenMagnetics 的合法波形和 MAS 映射。MKF complete 与 native Rdc 的历史口径差异会同时保留，不能把两者相加。
- 当前只固定真实磁芯，不优化磁芯类别/堆叠；绕组高度和厚度因生成器尚未可靠支持而未暴露。
- 体积目标是参数化绕组包络体积；固定磁芯外包络并未被虚构为可改善。
- 真实 Provider 未安装/不可用时，外部算例明确无解，不生成 synthetic 结果。
- 本阶段不改旧版演示 NSGA-II、不改旧版 `engine.py`、前端和生产依赖；前端可视化放在后续阶段。
