# 电磁一致性校核

## 独立磁阻计算

专项脚本从运行时 OpenMagnetics 数据库取得材料、磁芯和导线。材料为 `3C95`，磁芯为 `ETD 54/28/19`，气隙为 `0.1 mm`，原边总匝数为 `Np=20`。

| 参数 | 实际值 |
|---|---:|
| `Ae` | `2.799884090461257e-4 m²` |
| `le` | `0.12937894574793482 m` |
| 100 kHz 实部 `μr` | `2815.5` |
| 磁芯磁阻 | `130604.50558087525 A/Wb` |
| 气隙磁阻 | `284217.0210440317 A/Wb` |
| 总磁阻 | `414821.526624907 A/Wb` |
| 独立 `Np²/Rm` | `964.2701121479912 μH` |
| OpenMagnetics | `970.3195771705127 μH` |
| 相对差异 | `0.62345%` |

独立结果与第三方结果在要求的 1% 容差内。公式和数值由 `examples/ps_psp_consistency.py` 独立实现，未调用生产电感函数生成预期值。

## PS 与 PSP 实际第三方结果

| 项目 | PS | PSP | 相对差异 |
|---|---:|---:|---:|
| 励磁电感 | `970.319577 μH` | `970.319577 μH` | `0%` |
| 峰值磁密 | `0.044990746 T` | `0.044990746 T` | `0%` |
| 磁芯损耗 | `0.212934045 W` | `0.212934045 W` | `0%` |
| 完整绕组损耗 | `0.044091696 W` | `0.045282230 W` | 允许不同 |
| 欧姆绕组损耗 | `0.043703975 W` | `0.044907031 W` | 允许不同 |

完整绕组损耗不被强制相等，因为 P-S 与 P-S-P 的实体块位置、平均匝长和邻近场不同；本专项只将相同磁路、总匝数和端口激励下的励磁电感、磁通密度和磁芯损耗作为一致性指标。

## 简化与边界

该校核使用 OpenMagnetics `ZHANG` 磁阻、`IGSE` 铁损和 `MANIKTALA` 温度模型，运行状态为研发原型，`engineering_approved=false`。气隙边缘附加损耗、有限元场分布和工程认证不在本专项结论内。
