# 第三阶段：后续建议

第四阶段最值得优先做的是把“结构几何”和“工作点波形”继续统一到服务接口，并在进入优化器前建立独立的模型基准：

1. 补齐 MAS 适配器的正式 schema/版本探测和更多骨架坐标系；
2. 将导线 DC 电阻、温度系数、绝缘材料和工艺规则从数据库完整映射到 `WireGeometry`/`InsulationGeometry`；
3. 建立自研漏感能量法与 OpenMagnetics/测量的逐结构对比，不引入任意交错修正系数；
4. 完善 PSP 端部引出线、连接损耗和独立端口电容模型；
5. 评估磁芯组合、三维结构和外置电感的统一几何表达，在未验证前继续保持独立路径；
6. 设计计算服务选择器，让优化器只依赖项目接口，并为 native/openmagnetics/comparison 结果建立同一任务快照；
7. 在真实或受控实验数据可用后，再进行温升/热点和工程约束校核。

当前可以直接开展的最小后续任务是：在不接入 NSGA-II 的前提下，增加一个结构参数批量基准，比较 PS/PSP 的匝数、界面绝缘、窗口占用和第三方损耗变化，并把每个输入快照与 Provider 版本写入报告。
