# Phase 4B：模型限制和后续工作

## 当前可以复现的能力

- 读取真实 OpenMagnetics 利兹线记录并保留缺失字段。
- 基于 Phase 3 逐匝几何计算 PS/PSP 导线长度、Rdc 和温度影响。
- 对周期电流执行检查、重采样、DFT、DC/AC 分离和谐波截断量化。
- 通过实际 OpenMagnetics API 获得 per-meter 集肤电阻及完整绕组损耗分项。
- 对 P1/P2 作为同一原边电气绕组聚合，不重复施加或重复求和。

## 主要限制

1. 选定真实数据库记录没有成品 nominal 外径、绞距和独立电阻率；基准明确选择最大外径范围用于排布，不能代替制造数据。
2. `native_dc` 不是完整交流铜损模型；利兹束内部电流分布、股间邻近效应和外部邻近效应列为未建模机制。
3. `openmagnetics_skin` 只输出真实第三方集肤增量，仍以 partial 标识，缺少同一路径的邻近分项时返回 `MISSING_FIELD_DATA`。
4. OpenMagnetics full 的结果依赖其当前支持的 MAS/绕组几何表达和模型选项；没有把第三方值自动当作真值。
5. 未实施热阻网络、热点温度、三维端部磁场、组合磁芯高保真漏磁场或优化器接入。
6. 当前基准是研发原型，所有布局保留 `engineering_approved=false`。

## 下一步建议

优先获取实际样机利兹线的成品外径公差、绞距、股线绝缘结构、铜材电阻率和制造商 AC 损耗数据；随后用局部 FEM 或实测阻抗分离校核 OpenMagnetics 的 skin/proximity 分项，再考虑把已验证的损耗服务接入多目标优化。
