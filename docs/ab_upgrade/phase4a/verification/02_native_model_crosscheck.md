# 自研模型交叉校核

## 运行入口

独立脚本：`examples/phase4a_plus_verification.py`。

它在第三方隔离环境中重新生成 PS/PSP，分别调用 `native_basic`、`native_sectional`、`field_energy_profile`，再用脚本内独立的分段线性 MMF 积分复算预期值。独立 oracle 不调用生产漏感函数。

## 基准结果

| 项目 | PS | PSP |
|---|---:|---:|
| 自研主模型 | 0.818968 μH | 0.361705 μH |
| 自研 sectional | 0.818968 μH | 0.361705 μH |
| 总周期平均储能 | 4.094840×10^-7 J | 1.808523×10^-7 J |
| 独立 MMF oracle | 一致 | 一致 |
| 区间能量重构 | 通过 | 通过 |

PS 是两块单层、等高结构，因此 `native_basic` 闭式式与 `native_sectional` 的分段积分退化到同一假设，差异小于 `1e-12` 相对容差。PSP 使用 P1/S/P2 的实际分段边界，不能调用 `native_basic`。

## 物理不变量

已实际执行的检查：

1. PS/PSP 的原边总匝数为 20，PSP 的 P1/P2 电流相同且方向同向串联。
2. 副边为 `-4 A`、原边为 `1 A` 时总安匝为零。
3. 原边整体电流放大 3 倍时，漏感不变，能量变为 9 倍。
4. 改变原副边间距、导线外径和 PSP 分段比例会改变自研模型的实际输入和结果。
5. 改变参考端口后，副边参考漏感为原边参考结果的变比平方换算值。
6. 任一区间体积为正，储能和漏感贡献非负。
7. 不同绕组高度、零几何尺寸和不平衡短路电流均不会被静默计算。

## 分区数据

服务新增 `LeakageInductanceService.field_energy_profile()`，每个实际径向区间输出：

- `radial_start_m/radial_end_m`；
- 起止及中点 MMF；
- 起止及中点 `H_t`；
- 平均匝长、轴向高度、积分体积；
- 能量密度、区间能量和折算漏感贡献。

这些数据直接用于 `*.svg` 分析图，避免用示意曲线替代计算结果。

## 发现与处置

本专项没有发现需要修改物理公式的新增错误。代码新增的是可审计的分区输出和独立验证脚本/测试；没有修改旧版 `engine.py`、NSGA-II、前端或现有 Demo 计算路径。
