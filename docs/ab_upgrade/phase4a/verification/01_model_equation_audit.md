# 4A+ 漏感模型方程审查

## 结论摘要

当前自研结果由实际几何驱动的 1-D 窗口场模型得到，不是固定系数或预存结果。独立基准脚本对 PS、PSP 的 MMF、场强、体积和能量逐区间复算，结果与服务输出在 `1e-12` 相对容差内一致。当前没有发现新的单位、储能体积或参考端口换算错误；约 22 倍差异不能据此归因于自研模型“少乘了一个固定系数”。

## 代码与公式对应

代码位置：`backend/app/leakage/service.py`。

| 物理量 | 实际实现 | 单位 | 代码入口 |
|---|---|---|---|
| 径向边界 | 由 block 和 layer 的 `radial_start_m/radial_end_m` 去重排序 | m | `_sectional_intervals()` |
| 累计安匝 | `F(x)=sum(N_i(x) I_i)`；块内按径向占比线性增加 | A·turn | `_mmf_at()` |
| 切向场 | `H_t(x)=F(x)/h` | A/m | `_sectional_intervals()` |
| 场能量 | `W_i=0.5*mu0*l_i/h*integral(F^2 dx)` | J | `_sectional_intervals()` |
| 区间积分 | `integral(F^2 dx)=dx/3*(F0^2+F0*F1+F1^2)` | A²·turn²·m | `_sectional_intervals()` |
| 漏感 | `L=2*W/I_ref,rms^2` | H | `calculate()` |
| 参考端口 | 使用实际原/副边 RMS 电流重新归一化 | 无量纲换算 | `calculate()` |

这里的 `l_i` 是该径向区间的平均匝长，`h` 是等高绕组的实际轴向高度。能量体积为 `l_i*h*dx`，因此从 `H=F/h` 推导后只剩一个 `1/h`，即：

`W_sigma = mu0/(2*h) * integral(l(x)*F(x)^2 dx)`。

这不是把“每单位长度能量”直接当总能量；每个区间都乘了实际平均匝长、轴向高度和径向宽度。

## RMS、峰值和参考端口

自研接口要求有符号 RMS 电流，并要求副边短路安匝平衡：

`sum(N_i*I_i)=0`。

自研模型明确使用周期平均储能和 RMS 参考电流：

`L_sigma,ref=2*W_sigma/I_ref,rms^2`。

PS 的 `Ip=1 A`、`Is=-4 A` 时，副边参考漏感应为原边参考值的 `1/16`；独立测试和脚本均验证了这一点。整体把电流放大 3 倍时，能量放大 9 倍而漏感不变。

OpenMagnetics/MKF 的 leakage Energy 路径在当前实际安装版本中使用自己的源电流峰值/谐波归一化和场能量接口；因此不能只看到同一个 `2W/I^2` 外形就认定两者的 `I` 定义相同。这个差异需要 FEM 或实测继续确认，不能用固定 22 倍系数修正。

## 已检查的潜在错误

- mm/m：Phase 3 结构字段全部以 `_m` 进入漏感服务；MAS 映射也直接传 SI 米。真实数据库的磁芯、气隙和几何输入分别经过 provider/adapter 处理，没有发现毫米值直接进入服务的路径。
- `h^2`：当前实现为 `0.5*mu0*l/h*integral(F^2 dx)`。专项测试和独立 oracle 一致。
- 漏磁区域：窗口内所有由实际 block/layer 边界划分的区间都被积分；绕组界面使用相邻绕组平均匝长。端部、磁芯外部和气隙边缘场明确不在当前模型范围内。
- 安匝：P1/P2 作为串联原边要求相同电流；副边短路要求总安匝平衡。不平衡时返回 `MMF_IMBALANCE`。
- 参考端口：原边与副边使用各自实际 RMS 电流归一化，未将自漏感、互感矩阵和短路等效漏感混用。

## 范围限制

当前模型仅支持 PS/PSP、径向分块、轴向匝、径向层、所有绕组等高的 1-D 窗口场。不同高度、轴向错位、三维端部效应、气隙边缘附加场和组合磁芯高保真漏感会返回 `OUT_OF_MODEL_SCOPE` 或在文档中明确未建模。
