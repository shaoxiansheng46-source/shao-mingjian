# 差异根因与最小修复

## 分类结论

| 类别 | 结论 | 证据 |
|---|---|---|
| A 输入/单位不一致 | 未确认，当前证据不支持 | PS/PSP 的磁芯、材料、气隙、总匝数、频率和工况一致；独立励磁电感与 MKF 相差约 0.623%，说明核心 SI 量和总 Primary 匝数基本一致 |
| B 定义/参考/归一化 | 部分确认，仍需 FEM/实测量化 | 自研采用 RMS 周期平均能量；MKF Energy 路径采用自身的源电流峰值/谐波归一化。两者不能只按符号形式等同 |
| C 自研实现错误 | 本专项未发现新的 C 类错误 | 独立 oracle、分区能量重构、PS 闭式/sectional 退化、参考端口和电流缩放全部通过 |
| D 物理假设不同 | 已确认 | 自研为等高径向 1-D 当前片；MKF 使用自身场模型、离散/网格和逐匝几何处理，端部与三维场处理不同 |
| E 第三方实现/适用性问题 | 未确认 | MKF 可实际调用，PS/PSP 励磁电感和磁芯损耗一致；显式几何变化会改变 PSP 漏感，但还不能据此证明绝对值正确 |

## 已定位的差异来源

当前自研/MKF 比值为：

- PS：`0.818968/19.053366 = 0.0430`，MKF 约为自研 `23.26×`；
- PSP：`0.361705/7.824007 = 0.0462`，MKF 约为自研 `21.63×`。

这不是单一的 22 倍常数：PSP 的结构变化改变了两种模型的响应，且 MKF 的显式几何与默认 `wind()` 控制值也不同。因而只能把差异归入“参考归一化 + 场模型/三维边界 + 几何离散方式”的组合，不能把 22 倍作为校正因子。

## 最小必要代码变更

本专项没有修改漏感数值公式，也没有用 MKF 覆盖自研值。新增内容只有：

1. `LeakageInductanceService.field_energy_profile()`：把生产模型实际使用的区间 MMF、H、体积、能量和贡献显式输出；
2. `examples/phase4a_plus_verification.py`：独立 oracle、输入快照、显式/默认几何对照、敏感性、SVG 分区图；
3. `backend/tests/test_phase4a_plus_verification.py`：独立能量复算、能量重构、电流缩放、不适用范围测试；
4. 本目录七份专项文档。

## 是否需要强制修复

目前不需要强制把两种结果调成相等。若后续 COMSOL 或实测证明自研值存在系统偏差，应先定位是端部场、场能量体积、谐波/峰值归一化还是几何映射，再修改适用模型；不允许使用固定 22 倍或“PSP 改善系数”。

## 当前可用性分级

- `native_basic`：可用于符合其明确假设的等高单层 PS 研究基准；
- `native_sectional`：可用于等高、同柱、径向分段 PS/PSP 的快速相对比较和敏感性研究；
- `openmagnetics_comparison`：可用于记录第三方 Energy 结果和输入映射对照；不能单独作为真值；
- 工程认证/最终设计：三者均需 COMSOL 或实测短路数据校核。
