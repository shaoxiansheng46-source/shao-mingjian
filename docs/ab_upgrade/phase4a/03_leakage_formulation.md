# 4A 漏感公式与推导

## 分段 MMF 能量模型

沿绕组窗口径向取 `x`，所有支持绕组的有效轴向高度为 `h`。对任意径向位置，定义从窗口内侧累计到 `x` 的安匝函数：

`F(x) = Σ_i I_i N_i(x)`

其中 `N_i(x)` 是第 `i` 个实际绕组层在 `x` 之前已经包含的匝数，`I_i` 是有符号 RMS 电流。均匀轴向电流片近似给出：

`H_t(x) = F(x)/h`

对应的周期平均漏磁场储能为：

`W_sigma = ∫ [1/2 μ0 H_t(x)^2] · l(x) · h dx`

即：

`W_sigma = μ0/(2h) ∫ l(x) F(x)^2 dx`

`l(x)` 使用实际层的平均匝长；绝缘区使用邻接绕组平均匝长。由于同一层内 `F(x)` 是线性的，每个径向小区间 `[x0,x1]` 的积分采用：

`∫ F² dx = Δx/3 · (F0² + F0F1 + F1²)`

最后按参考端口 RMS 电流：

`L_sigma,ref = 2 W_sigma / I_ref,rms²`

服务同时输出每个层/界面的 `energy_j` 和折算漏感贡献。

## Model A：PS 基础解析式

在两块单层、等高 PS 且原副边安匝平衡时，分段积分退化为：

`L_sigma,p = μ0 Np² l_mlt / h · (tp/3 + gps + ts/3)`

其中 `tp/ts` 是原副边实体径向厚度，`gps` 是两块实体边界间距，`l_mlt` 是两块平均匝长的平均值。`1/3` 来自均匀电流片内部 `F²` 的积分；它不是交错改善系数。

Model A 只作为明确限制下的快速闭式计算，不声称是引用论文的完整 Rogowski/三维模型。

## 参考端口换算

同一储能使用不同端口电流归一化。平衡变比下，若 `Ip/Is = Ns/Np`，则：

`L_sigma,s = L_sigma,p · (Ip/Is)²`

服务直接使用输入的实际有符号 RMS 电流进行换算，不把原边自漏感、副边自漏感、互感矩阵和短路等效漏感混为一个字段。
