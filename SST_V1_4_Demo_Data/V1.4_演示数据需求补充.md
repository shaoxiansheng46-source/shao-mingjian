# V1.4 演示数据实施补充

## 1. 要求

MVP 应内置本包四类材料/规格库及排布模板的虚构数据，并补充设计规则及模型登记表，默认提供“演示项目”。虚构数据属于开发和流程验证阶段的正式交付内容；不要求在流程联调前先具备真实厂家数据库。

演示模式允许合成磁芯、磁性材料、利兹线、绝缘、热阻和交流电阻模型，其核心要求是字段完整、关系自洽、结果可追踪、正反例可运行。不能把虚构条目命名为 PC95、3C95、EE85 等真实厂家材料或型号，避免误识别。

## 2. 数据与模式隔离

所有条目包含 DEMO_ ID、revision、synthetic 状态、来源说明和 engineering_approved=false。结果和导出同样保留 demo_only 标签。工程模式采用严格校验，不能自动移除标签或补入演示值。

生产软件应支持替换为真实数据而保留同一字段规范。真实数据需要新增真实 ID、数据来源、有效范围和审核记录，不能直接把虚构数据状态改成 manufacturer。

## 3. 验收

- 默认正例完成输入→数据库→候选→排布→电气/损耗/热→约束→Pareto→报告流程。
- 一个无解样例返回可读失败原因，不生成伪方案。
- 一个工程模式样例明确拒绝 synthetic 数据。
- 一个非支持波形样例阻断，不静默使用 50% 方波。
- 默认参数至少形成两个损耗—体积权衡的前沿点。
- 未实现的模板 enabled=false，不能进入优化候选。
- demo 流程验收不等同于工程误差指标、NSGA-II 算法或全功能软件验收。

这份补充不放宽 V1.4 的工程模式数据与模型验收要求。
